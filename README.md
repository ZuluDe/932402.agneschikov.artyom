# Лабораторная работа 5. DOM и взаимодействие с элементами страницы 

**Выполнил:** Агнещиков Артём вариант 9

## Описание
Интерактивный веб-интерфейс на тему Музыкант и звукорежиссёр с динамическим управлением DOM-деревом
Реализован интерактивный плейлист треков переключение темы оформления и сохранение данных в localStorage
Все изменения интерфейса происходят динамически без перезагрузки страницы

## Выполненные требования задания
В коде реализованы все обязательные элементы и требования Варианта 9

* Поиск элементов в DOM
    Поиск кнопок управления по идентификатору через getElementById
    Поиск контейнера списка по классу через querySelector
    Выборка элементов треков через querySelectorAll

* Манипуляции с DOM и плейлист
    Динамическое создание элементов списка через createElement и appendChild
    Добавление трека с полями названия длительности чекбоксом Избранное и кнопкой удаления
    Удаление выбранного трека напрямую через метод remove
    Полная очистка плейлиста через перебор элементов с выводом предупреждения при пустом списке

* Интерактивность и стили
    Переключение между тёмной и светлой темами по кнопке с обновлением CSS-переменных
    Скрытие и показ блока плейлиста по клику через класс hidden

* Работа с localStorage и обработка ошибок
    Сохранение структуры плейлиста статусов чекбоксов и выбранной темы в localStorage
    Восстановление данных и темы оформления при перезагрузке страницы
    Проверка существования элементов перед манипуляциями с выводом ошибок в консоль

## Как запустить

Откройте файл index.html в любом браузере. Убедитесь, что:
1. Файл `script.js` находится в одной папке с `index.html`
2. Файл `style.css` и папка `files` находятся в том же каталоге
3. Для проверки сохранения состояния перезагрузите страницу после добавления треков или смены темы
